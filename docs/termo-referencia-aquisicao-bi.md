## 1. Requisitos de negócio

**Processo:** Termo de Referência — Contratação TIC 0088567

A contratação tem por objeto a aquisição de ferramenta de *Business Intelligence* para atender aos seguintes requisitos:

| # | Requisito | Finalidade |
| --- | --- | --- |
| R1 | Modelagem dimensional dos dados de conformidade | Organizar os dados de registro de gestão em modelo analítico |
| R2 | Conexão com as fontes de dados do processo | Acompanhar a base de conformidade sem coleta manual |
| R3 | Atualização agendada | Garantir indicadores vigentes sem intervenção manual |
| R4 | Construção de indicadores calculados | Calcular KPIs de conformidade, produtividade e tempestividade |
| R5 | Publicação e compartilhamento de painéis | Disponibilizar as visões às unidades gestoras |
| R6 | Controle de acesso | Restringir a visualização conforme o perfil do usuário |

*(A seção 2 do documento original não foi preenchida.)*
